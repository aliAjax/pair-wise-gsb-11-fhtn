# 油站防静电接地巡检与复测放行台

- 行业：石油
- 技术栈：React、Vite、TypeScript、Zustand、Ant Design
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

按区域、设备、接地点和班次记录接地电阻与仪器检定日的合规闭环原型，数据保存在浏览器 localStorage。

## 业务规则

- 同一接地点同一班次仅允许一条记录；
- 仪器检定失效或电阻超过 4Ω 即停在异常并保留输入，自动生成异常单；
- 区域存在未放行异常时，该区域不得登记正常；
- 复测须换班（不得与异常登记班次、已合格复测班次重复），两次合格才放行；
- 放行后冻结读数与班组，改动须另建原因版本并保留旧值；
- 受阻时列出规则、原值、现值；重载后点位、异常、复测与版本保持对应。

## 代码分层（资料、判定、存储、界面相互独立）

- `src/data/master.ts`：资料层——区域、设备、接地点、班次、仪器与阈值；
- `src/data/seed.ts`：初始演示数据（覆盖正常/待复测/复测中/已放行含版本）；
- `src/domain/types.ts`、`src/domain/rules.ts`：判定层——纯函数规则，受阻返回规则/原值/现值；
- `src/storage/persist.ts`：存储层——localStorage 读写与模式版本；
- `src/App.tsx`：界面层——只负责渲染与交互编排。
