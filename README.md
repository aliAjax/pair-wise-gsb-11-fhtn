# 油站防静电接地巡检与复测放行台

- 行业：石油
- 技术栈：React、Vite、TypeScript、Zustand、Ant Design（基础样式）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 规则/流程冒烟测试：`npm test`（判定引擎 28 项 + 全流程 33 项，经 esbuild 即时编译，不经过界面）

## 业务闭环

按区域 → 设备 → 接地点 → 班次记录接地电阻与仪器检定日：

1. **同点位同班仅一条**：重复登记直接受阻，面板列出原值、现值与命中规则。
2. **异常停住并保留输入**：仪器勾选失效、检定日缺失或超过 12 个月有效期、电阻读数无法识别或 **超过 4Ω**，即判为异常并原样保留本次输入（班组、读数字符串、检定日等）。
3. **区域闭锁**：区域内存在未放行异常时，复测放行前该区域不得登记“正常”（仍可登记异常），总览中区域显示闭锁态。
4. **复测换班**：复测班次必须与上一次有效尝试（无尝试时与原登记班次）互斥；不符合换班的提交被拦截，不产生复测记录。
5. **两次合格放行**：复测须连续两次换班合格才放行；中途不合格则连续性中断，需重新累计两次。每次复测（含不合格）都留存读数、仪器与判定。
6. **冻结与版本**：放行时冻结读数与班组；任何改动必须填写原因并另建版本，旧值逐行保留。台账同时展示冻结值与版本更正后的现值。

所有受阻场景统一以「规则 + 原值 / 现值对照表」呈现；数据保存在浏览器 localStorage，刷新/重载后点位、异常、复测与版本对应关系一致。

## 分层结构（四层独立）

| 层 | 目录 | 职责 |
| --- | --- | --- |
| 资料 | `src/domain/catalog.ts` | 区域、设备、接地点、班次、班组、仪器目录；不依赖存储与界面 |
| 判定 | `src/domain/rules.ts` | 电阻 4Ω、检定 12 个月、仪器失效、同班唯一、区域闭锁、换班、版本校验；纯函数 |
| 存储 | `src/data/storage.ts` | localStorage 读写、序列化与演示数据；不含任何规则 |
| 状态/界面 | `src/state/store.ts`、`src/ui/*` | 串联判定与存储的操作、登记台、异常/复测看板、已放行台账与点位总览 |

界面三个标签页：**点位总览**（区域闭锁态 + 点位↔记录↔版本对应）、**异常与复测**（内嵌复测台与放行时间线）、**已放行台账**（冻结值/现值 + 原因版本）。
